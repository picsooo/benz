# Benz Promotion Immobilière — Maquette site vitrine

Maquette HTML statique (V1) réalisée par Webminds.

- `index.html` — page d'accueil (slider plein écran, résidences, plans, prestations, galerie, localisation, contact)
- `appartement-temoin.html` — modèle de page « Appartement témoin » (Type F4-a, Résidence Mascula)
- `css/style.css` — styles communs
- `fonts/` — polices embarquées (Cormorant Garamond, Manrope, Pinyon Script) — fonctionne hors ligne
- `images/` — visuels optimisés des résidences Cirta, Mascula, Numidia, Massily

Ouvrir `index.html` dans un navigateur, aucun serveur nécessaire.
